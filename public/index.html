      Advanced setup

      Create your personal Google OAuth app

      You will create a Web application in your own Google Cloud project, then authorize the Gmail account that should send messages.

      1. 1

        Create or select a Google Cloud project ↗

      2. 2

        Enable the Gmail API ↗

      3. 3

        Configure Branding, set an External Audience, and add your Gmail address as a test user.

      4. 4

        Under Data Access, use only openid, email, profile, and https://www.googleapis.com/auth/gmail.send.

      5. 5

        Open Clients, create a Web application, and register the exact return address shown here.

      Testing mode reconnects after 7 days. Google expires test-user authorization, including the refresh token, after seven days when Gmail access is requested. Publish and verify your OAuth app for longer-lived access.
      Authorized redirect URI Google’s return address
      Paste this exact value under Authorized redirect URIs. Scheme, host, path, and trailing slash must match.
      Personal OAuth app storage is unavailable until the deployment has database encryption and a public callback URL.
